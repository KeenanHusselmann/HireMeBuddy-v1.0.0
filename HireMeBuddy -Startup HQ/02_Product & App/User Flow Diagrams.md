# User Flow Diagrams

## Client Booking Flow
```
1. App Launch
   ↓
2. Authentication
   ↓
3. Browse Providers (Video Feed)
   ↓
4. View Provider Profile & Portfolio
   ↓
5. Initiate Booking
   ↓
6. Enter Job Details
   ↓
7. Confirm Booking
   ↓
8. Payment
   ↓
9. Track Booking Status
   ↓
10. View Completion Report
   ↓
11. Rate & Review
```

## Provider Flow
```
1. App Launch
   ↓
2. Authentication
   ↓
3. View Bookings
   ↓
4. Accept/Decline Booking
   ↓
5. Complete Job
   ↓
6. Submit Completion Report
   ↓
7. Receive Payment
```

## Admin Flow
```
1. Admin Login
   ↓
2. Dashboard View
   ↓
3. User Management / Provider Verification / Dispute Resolution
   ↓
4. Take Action
```
