# Archive

## Purpose
This folder contains old versions, unused ideas, and deprecated documents. Files are moved here instead of being deleted to maintain historical record.

## Guidelines

### What Goes Here
- Superseded documents (old versions)
- Rejected ideas and proposals
- Deprecated features
- Old meeting notes (>6 months)
- Unused marketing materials
- Previous roadmap versions

### File Naming Convention
When archiving, rename files to include date:
```
[YYYY-MM-DD] Original_Filename.md
```

Example:
```
2025-12-13 Old_Business_Model.md
```

### Organization
- Maintain folder structure from original location
- Add context note at top of archived file explaining why it was archived

### Archive Template
```
---
ARCHIVED: [Date]
REASON: [Why this was archived]
REPLACED BY: [Link to new document if applicable]
---

[Original content below]
```

## Retention Policy
- Keep archived files for minimum 2 years
- Review annually for permanent deletion
- Legal/compliance docs: Keep indefinitely
